Click on Results button to view submitted results when test was/is Active.

-------------------------------------------------------------------------------------------

 

This is the panel where you can see all submitted results along with score of each students.

You can delete any submission by clicking on delete icon.

Rank mode: if you turn on the rank mode. All students will arrange acording to decreasing order of their marks.

Rank by Merit:

  • Score (highest first)
  • Incorrect (fewest first)
  • Skipped (fewest first)
  • Submission time (earliest first)

 

Download excel: you can download full report of each students in excel sheet and can publish after exam.

 

Click on detailed analysis icon to see full performance of any student.
