**Description**
Solving DPPs on paper with a clock behind you isn't how exam day feels.

Snap your DPP pages, snap the answer key, and TestoZa turns them into a timed online test: +4 / −1 marking, a real timer, a question palette, and an instant result that shows your score, what you got wrong and where your time went.

Works for JEE, NEET, SSC, Banking or any exam's practice sheets. PDFs work too.

1. Open testoza.com → Generate with AI
2. Choose File → Take Photo → snap each DPP page
3. Answer key → Take Photo → snap the key page
4. Set marking (+4 / −1) → Extract Questions
5. Check the questions → Save & continue → My Tests
6. Preview → Start Test Now → attempt → Submit → see your result

Everything in this video is a real run on app.testoza.com on a phone: 12 questions read from two photos and matched to the answer-key photo in 31.9 seconds.
