# Script — How to Conduct a Cheat-Proof Online Exam (EN)

One `## Lnn` block = one voice clip. Indented lines are spoken. `{cue}` marks the word an on-screen
action must land on (the click/appear moment is pinned to the start of the word after the cue).
Cues are stripped before text-to-speech. `[chapter]` lines are YouTube chapters.

## L08 · Violation action
**Shot:** hover Warn only → hover Strict → click the warnings option, open the number, pick 3.
**Delivery:** a little conspiratorial on "my favourite".

    And full-screen exits count toward the same limit.
