## Upload steps (YouTube Studio)
1. **Details → Language and captions:** Video language = **English**. Title & description language = **English**. (The original language must be set before Studio lets you add another audio track.)
2. **Subtitles → Add language → Hindi.**
3. On the Hindi row:
   - **Audio → Add →** upload `testoza-live-exam-hindi-audio-v1.wav` → Publish.
   - **Title & description → Add →** paste the Hindi title and description below → Publish.
   - **Subtitles → Add → Upload file → With timing →** `youtube/hi/captions-hi.srt` → Publish.
4. On the English row: **Subtitles → Upload file → With timing →** `youtube/captions-en.srt`.
5. Check: open the video, then ⚙️ → **Audio track → Hindi**. The voice should match the clicks on screen.

If the Hindi row has no **Audio** column, this channel doesn't have multi-language audio yet. In that case, upload `testoza-live-exam-hi-v1.mp4` as a separate Hindi video, set Video language = Hindi, use the Hindi text below, and link the two videos to each other.

YouTube picks the voice automatically from the viewer's language, so Hindi viewers will hear Hindi without touching ⚙️.
