### Add the Hindi audio track (YouTube Studio)

1. Upload the English video and publish (or schedule) it as usual.
2. Studio → **Languages** → set the video language to **English** → **Add language → Hindi**.
3. In the Hindi row: **Audio → Add** → upload `testoza-understanding-results-hindi-audio-v1.wav` → Publish.
4. Same Hindi row: **Title & description → Add** → paste the Hindi title/description below.
5. **Subtitles → Add → Upload file → With timing**: `captions-en.srt` (English), `captions-hi.srt` (Hindi).

If the channel doesn't offer multi-language audio yet, upload a separate Hindi video: the English
picture with the Hindi WAV as its sound (I can make that MP4 on request).
