Hello! Today we take this JEE Main sample paper
and build a complete test on TestoZa from selected questions.
Every question teaches you something new. Let's begin.
Click Create Test in the menu on the left.
At the top, type the test name — JEE Main Mini Mock.
Below it, a one-line description candidates see before they start.
Now pick the time. The 3h button sets 180 minutes.
"Only my students" means only people you send the link to can see it.
In Marking, choose JEE / NEET: +4 for right, −1 for wrong.
Open Institution branding to add your institute name and logo.
Now go down to Questions. The first one is physics.
Let's type it in English first.
Now the same question in Hindi.
Click the button next to English and pick Hindi from the menu.
Type in English letters — each word turns into Hindi when you press space.
The Hindi version goes right below the English one.
Options need a square root: open Maths & symbols. This is Sy Pad.
Click option A, write the root, press Insert.
All four options done. Click the correct letter — D. One question, two languages.
Press Add question. Tip: a new question opens in the last language, so tap English first.
This question has a diagram — no need to redraw it.
Picture → the screen button. In the PDF press Win + Shift + S, box the diagram, then Ctrl + V.
The diagram sits under the question and above the options, just like the paper.
Fraction options from Sy Pad. Correct answer: B.
Question 3 is chemistry, and the structure sits inside the sentence.
TestoZa has no structure-drawing tool, so we cut it from the paper.
Picture → the cloud button places it exactly where your cursor is.
Then the reaction arrow from Sy Pad: ozone above, zinc and water below.
It's numerical: Question type → Numerical answer → Exact value → 1.
Now maths. Open Maths & symbols — "Goes into Question 4".
f(x) = integral… a fraction… x² dx on top…
…and (1 + x²)(1 + √(1 + x²)) below.
The preview builds it exactly like the paper. Insert, then finish the line.
Log, root and π/4 options — all from Sy Pad. Correct answer: B.
Now the biggest question in this video: a JEE-level multistep reaction.
First the bromobenzene structure, placed at the cursor.
In Sy Pad → Chemistry, pick the arrow with conditions. Three rows on top, none below.
The reagents: Mg and ether, then CO₂ and H⁺; NH₃ and heat; Br₂ and NaOH.
The options are structures too — a picture in each option.
Five diagrams in one question, still clean. Correct answer: B — aniline.
Match-the-list needs no table drawing.
Sy Pad → Tables → Match List. Reactants left, products right, then Insert.
Correct answer: C.
The paper is ready. Now split it into Physics, Chemistry and Mathematics, like real JEE.
First, drag the integral question to the bottom by its handle.
Switch on "Split into sections" — everything lands in Section A.
Click the + between two questions → New question here.
One more chemistry question, with Sy Pad's chemistry keys.
Press "Add a new section", name it Bonus, and add a maths question.
Now split Section A: click + where chemistry starts → Split section here.
Name the first part Physics and the new one Chemistry.
The integral is still in Chemistry — split it out and name it Mathematics.
Finally, merge Bonus into Mathematics.
Physics, Chemistry, Mathematics — just like JEE.
Click Save test. Your test is now in My Tests.
And this is exactly what your candidates see — sections, Hindi, diagrams, maths.
